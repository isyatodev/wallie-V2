            🔧 Install Kokoro — free local voice (no API key)
            
          
          

            

              
              
              
              
              
            

            

            

              Want a better free voice than Piper? Kokoro runs on your PC: no key, no
              per-word cost. It needs PyTorch (a few hundred MB) and Python 3.10–3.12
              — the multilingual wheels have no 3.13+ builds. Run these from the project
              folder with your venv Python.
            

            
    
              
  1. 
                1 · Install the packages
                python scripts/install_kokoro.py --install
                Manual equivalent: pip install "kokoro>=0.9.4" soundfile
              
    2. 
              
  2. 
                2 · Download the model + a voice (works offline afterwards)
                python scripts/install_kokoro.py --lang p --voice pf_dora
                
                  Pre-downloads hexgrad/Kokoro-82M and the chosen voice into the
                  HuggingFace cache. Non-English packs need kokoro>=0.9.4;
                  Japanese/Mandarin also add misaki[ja] / misaki[zh]
                  (--install) plus a system espeak-ng.
                
              
    3. 
              
  3. 
                3 · Switch to it in the Voice tab
                
                  Set Provider → Kokoro (local · free), pick the Language
                  (e.g. Portuguese (Brazil)) and a Voice (pf_dora /
                  pm_alex / pm_santa), then press ▶ Play to
                  hear it. You can finish setup now and do this later.
                
              
    4. 
            

          

        

      


      
      

        

          
🎉

          
You're all set

          
Your streamer is configured. Hit start and Wallie-Kansai comes alive — or fine-tune anything in the dashboard first.
